# MediFrame updates (macOS / Sparkle)

Public feed used by [Sparkle](https://sparkle-project.org/) to update MediFrame on macOS.

| File | Where it lives |
|---|---|
| `appcast.xml` | this repo (GitHub Pages) |
| `MediFrame-X.Y.Z-macos.zip` | [GitHub Releases](https://github.com/josuegmo97/mediframe-updates/releases) |

Feed URL (embedded in the app):

https://josuegmo97.github.io/mediframe-updates/appcast.xml

This repository does **not** contain the EdDSA private key. Source code stays in the private `mediframe` repo.
